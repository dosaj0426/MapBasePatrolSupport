# 위치 일괄 등록 CSV 양식

관리자 지점 관리 → 새 지점 등록 왼쪽의 **위치 파일 추가** → CSV 선택 → **파일 검사·미리보기** → 정상 항목 확인 → **일괄 등록** 순서로 사용합니다.

| 열 이름 | 필수 | 값과 기본값 |
| --- | --- | --- |
| 지점명 | 필수 | 1~100자 |
| 분류 | 필수 | 1~80자. 시설 점검, CCTV, 여성 1인 사업장 등 |
| 도로명주소 | 필수 | 도로명과 건물 번호. 네이버 Geocoding으로 좌표 변환 |
| 우편번호 | 선택 | 5자리 숫자 문자열. 비우면 주소 변환 결과 사용 |
| 상세주소 | 선택 | 동·층·호수, 200자 이내 |
| 아이콘이름 | 선택 | 서버에 등록된 아이콘의 정확한 이름. 비우면 기본 아이콘 |
| 강화구역 | 선택 | Y 또는 N. 기본 N |
| 반지름(m) | 선택 | 5~10000. 기본 50 |
| 완충배수 | 선택 | 1 초과~10. 기본 1.5 |
| 알림타입 | 선택 | info / warning / danger / emergency. 기본 warning |
| 음성안내 | 선택 | 500자 이내. 비우면 지점 이름을 포함한 기본 안내 |

- UTF-8 BOM으로 만든 양식·테스트 파일을 제공합니다. CP949 CSV도 읽을 수 있습니다.
- 최대 1MB, 데이터 50행입니다. 빈 행은 제외합니다.
- 쉼표가 들어간 값은 큰따옴표로 감싸고, 값 안 큰따옴표는 두 번 작성합니다. 일반 CSV 저장 기능을 사용하면 자동 처리됩니다.
- 우편번호 앞의 0이 사라지지 않게 문자열로 저장하세요.
- 필수 열 외의 열은 생략할 수 있지만 알 수 없는 열·중복 열 이름은 허용하지 않습니다.
- 이름·변환된 주소·상세주소가 같은 지점은 기존 목록과 파일 내부 모두에서 중복 검사합니다.
- 오류가 하나라도 있으면 전체 등록을 막습니다. 파일 수정 후 다시 검사해 주세요.
- 미리보기 유효기간은 1시간이며, 같은 미리보기의 등록 요청은 한 번만 반영됩니다.
- 업로드만으로 등록하지 않습니다. 미리보기 후 일괄 등록 버튼을 눌러야 저장합니다.
- 테스트 CSV는 실제 시설 주소를 사용한 가상 지점 3개입니다. 이름에 [CSV 테스트]가 붙으며 강화구역은 모두 N이라 구역 진입 알림을 만들지 않습니다.
- 강화구역 Y로 등록하면 기존 지점 등록과 같이 안내 음성 사전 생성을 시도합니다. 환경에 따라 시간이 걸릴 수 있습니다.
